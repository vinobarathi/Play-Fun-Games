# Play Fun Games

A single-page mini-games hub built with vanilla HTML, CSS, and JavaScript, no frameworks or dependencies.

Live demo: https://vinobarathi.github.io/Play-Fun-Games/

## Games included

Tic-Tac-Toe: two-player grid game with win and draw detection.
Rock-Paper-Scissors: play against a randomized computer opponent.
Guess the Number: number-guessing game between 1 and 10 with high or low feedback.
Dice Roller: simulates rolling two dice.

## Tech stack

HTML5 for structure.
CSS3 for styling, including custom gradients, box shadows, and responsive layout.
Vanilla JavaScript for all game logic: DOM manipulation, event handling, no libraries.

## Running locally

Clone the repo and open index.html directly in a browser. No build step or server is required.

Repository: https://github.com/vinobarathi/Play-Fun-Games
